# 食光 · 健康饮食 App 设计规范（DESIGN.md）

> 定位：面向 25–40 岁关注体态与健康的都市用户，每天打开 App 完成两件事——**快速记一餐、看今日营养缺口**。
> 命名「食光」：谐音"时光"，把每一餐记成时光。

## 1. 视觉方向

原型从"菜市场与厨房食材"取意象，而非通用后台式的灰白配色：

- 底色是**糙米与菜叶的米绿白**，卡片留白呼吸感强；
- 主色为**抹茶绿**（食材、生长、克制）；
- 三大营养素各有一味"食物色"：碳水=谷物黄（米饭、燕麦），蛋白质=浆果红（瘦肉、番茄），脂肪=深海蓝（鱼油）——营养素颜色全 App 统一，用户看色即知营养；
- 警示用**南瓜橙**，只在热量接近/超出目标时出现，保持克制。

## 2. 色彩令牌（css/design-tokens.css 为唯一事实来源）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F6F8F1` | 页面底色 · 米绿白 |
| `--surface` | `#FFFFFF` | 卡片面 |
| `--surface-soft` | `#EEF3E6` | 浅色卡片面 |
| `--ink / --ink-2 / --ink-3` | `#26331F / #5D6B53 / #9AA88F` | 主/次/弱文字 |
| `--line` | `#E3E8D8` | 分隔线 |
| `--primary / --primary-deep / --primary-soft` | `#3D7A4F / #2B5C39 / #E1EFDC` | 主操作/按压/浅底 |
| `--nut-carb` | `#E5A33C` | 碳水 · 谷物黄 |
| `--nut-protein` | `#C75B4B` | 蛋白质 · 浆果红 |
| `--nut-fat` | `#5E8FA8` | 脂肪 · 深海蓝 |
| `--warn` | `#D9662B` | 热量提醒 |
| `--danger` | `#B8402F` | 删除/超标 |

## 3. 字体

| 角色 | 字体 | 用法 |
|---|---|---|
| 展示/数字 | `Fraunces`（有机衬线） | 餐盘环中心大数字、体重、目标值——数字带一点"食材标签"的温和感 |
| 中文正文 | `Noto Sans SC`（回退 PingFang / 雅黑） | 全部界面文字 |

字号阶梯：`12 / 13 / 15 / 17 / 22 / 44px`，大数字用 `tabular-nums` 防跳动。

## 4. 圆角 · 间距 · 阴影

- 圆角：卡片 `22px`，小控件 `10–16px`，按钮/进度条 `999px`；
- 间距：4px 基准（`--sp-1` 到 `--sp-8`），页面左右留白 20px；
- 阴影两级：`--shadow-card`（卡片）、`--shadow-float`（手机壳/浮层），不做多层叠影。

## 5. 签名元素：营养餐盘环

首页顶部的 SVG 圆环是全 App 的记忆点，意象来自"膳食指南餐盘俯视"：

- **外环** = 今日热量进度（抹茶绿；超出目标变南瓜橙）；
- **内环** = 三大营养素按克重比例分段（黄/红/蓝），颜色语义全局一致；
- **中心** = 剩余可摄入 kcal，用 Fraunces 大数字。

记录/删除食物后环即时重算，形成"吃一口、盘子里就少一块"的反馈感。

## 6. 动效

- 界面切换：8px 上浮淡入（`--ease` 弹性曲线）；
- 弹层：底部 Sheet 上滑 340ms，遮罩淡入；
- 进度条/环：数据变化时 0.5s 过渡；
- 遵循 `prefers-reduced-motion`，弱动效环境全部动画置空。

## 7. 文案基调

- 动词开头、说人话：按钮写「记一笔」「拍照识别」，不写「提交」「上传图片」；
- 空状态给行动方向：「这一餐还没记录，点下方『记一笔』」；
- 错误与"敬请期待"直说原因，不卖惨不夸张。
