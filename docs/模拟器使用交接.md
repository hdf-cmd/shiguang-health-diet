## 2. 启动 / 停止模拟器

```powershell
# 启动（冷启动，约 25-30 秒）
$env:ANDROID_HOME = "C:\Users\24755\AppData\Local\Android\Sdk"
$env:PATH = "$env:ANDROID_HOME\emulator;$env:ANDROID_HOME\platform-tools;$env:PATH"
Start-Process -FilePath "$env:ANDROID_HOME\emulator\emulator.exe" `
  -ArgumentList "-avd","medium_phone","-no-snapshot-load","-no-boot-anim" -WindowStyle Normal

# 等开机（输出 1 = 完成）
for ($i = 0; $i -lt 60; $i++) {
  Start-Sleep -Seconds 3
  if ((adb shell getprop sys.boot_completed 2>$null | Out-String).Trim() -eq "1") { break }
}

# 停止（三选一）
adb emu kill                                  # 优雅；注意：AI 沙箱里可能被拒
Stop-Process -Name "qemu-system-x86_64" -Force   # 沙箱内可用这个
# 或直接关模拟器窗口
```

坑：
- `adb emu kill` 在 AI 工具沙箱里会"拒绝访问" → 用 `Stop-Process`。
- adb 在**个别终端会话**间歇性"拒绝访问" → 换一个新 Bash 会话重试即可，不是真故障。
- 开机后若 `am start` 太早会落到桌面 → 开机完成后再 start，或补一次 `am start`。

## 3. 安装 / 启动 / 重启 App

```powershell
adb install -r "c:\Desktop\健康饮食app\食光-debug.apk"   # 覆盖安装，保留登录态/数据
adb shell am force-stop com.healthydiet.app              # 杀进程
adb shell am start -n com.healthydiet.app/.MainActivity  # 启动
adb uninstall com.healthydiet.app                        # 卸载（丢登录态，云端数据不丢）
```

- `install -r` 保留 WebView localStorage（登录态）与虚拟机磁盘数据；`-no-snapshot-load` 只跳过快照、不丢数据。
- 构建新 APK：`cd HealthyDiet && gradlew.bat assembleDebug`（需先设 JAVA_HOME），产物在 `app\build\outputs\apk\debug\app-debug.apk`，拷到工作区根目录再 install。
- **x86_64 模拟器装不了 arm64-only 的 APK**（`INSTALL_FAILED_NO_MATCHING_ABIS`），当年搜狗输入法就死在这。

## 4. CDP 调试连接（核心技能）

App 是 WebView 壳，可用 Chrome DevTools Protocol 直接执行 JS / 截图：

```powershell
$p = (adb shell pidof com.healthydiet.app).Trim()
adb forward --remove-all
adb forward tcp:9222 localabstract:webview_devtools_remote_$p
```

Python 模板（websocket-client 已装）：

```python
import json, urllib.request, websocket, time, subprocess
ADB = r"C:\Users\24755\AppData\Local\Android\Sdk\platform-tools\adb.exe"
t = [x for x in json.load(urllib.request.urlopen("http://127.0.0.1:9222/json"))
     if x.get("type") == "page"][0]
ws = websocket.create_connection(t["webSocketDebuggerUrl"], suppress_origin=True, timeout=25)

def ev(expr, wait=0, awaitp=False):
    ws.send(json.dumps({"id": 1, "method": "Runtime.evaluate",
                        "params": {"expression": expr, "returnByValue": True,
                                   "awaitPromise": awaitp}}))
    deadline = time.time() + 30
    while time.time() < deadline:
        m = json.loads(ws.recv())
        if m.get("id") == 1:
            if wait: time.sleep(wait)
            return m["result"]["result"].get("value")

def shot(path):   # 截图
    with open(path, "wb") as f:
        f.write(subprocess.run([ADB, "exec-out", "screencap", "-p"],
                               capture_output=True).stdout)
```

要点：
- `suppress_origin=True` 必须有，否则握手被拒。
- 异步表达式（返回 Promise）必须 `awaitp=True`，否则拿到 `{}`。
- 页面顶层 `const/let`（如 `state`、`bsMap`、`mainSwiper`）在 evaluate 里**可直接访问**（同一全局词法环境）。
- PowerShell here-string 传中文给 python 会 GBK 乱码 → 验证脚本 print 用英文标签或 `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`
- **App 重启后 pid 会变**：`am force-stop` + `am start` 之后旧 forward 指向死进程，必须重新 `pidof` → `forward --remove-all` → 重新 forward，否则 CDP 连不上（或连到上次的旧页面）。
- **截图落盘走 MCP**：`android_screenshot(serial, path="…工作区相对路径.png")` 可直接把图存进工作区归档；若在 python 里用 `adb exec-out screencap` + `open(路径)` 写文件，会被 Mimosa 钩子判成「命令注入/路径穿越」拦掉 —— **CDP 脚本只做 `Runtime.evaluate`，截图交给 MCP 工具**。

## 5. 合成事件验证（模拟手指）

**点按（tap）**——目标必须用 `elementFromPoint` 取真实命中元素（按钮文字通常是内层 span）：

```js
window.tTap = function(sel) {
  var el = document.querySelector(sel);
  var r = el.getBoundingClientRect();
  var x = r.left + r.width/2, y = r.top + r.height/2;
  var real = document.elementFromPoint(x, y) || el;
  var t0 = new Touch({identifier: Math.floor(Math.random()*1e6), target: real,
                      clientX:x, clientY:y, pageX:x, pageY:y});
  real.dispatchEvent(new TouchEvent('touchstart',{touches:[t0],changedTouches:[t0],bubbles:true,cancelable:true}));
  real.dispatchEvent(new TouchEvent('touchend',{touches:[],changedTouches:[t0],bubbles:true,cancelable:true}));
};
```

**横滑切屏（Swiper 吃 PointerEvent）**：

```js
window.pSwipe = function(sel, dx) {
  var el = document.querySelector(sel);
  var r = el.getBoundingClientRect();
  var x = r.left + r.width/2, y = r.top + r.height/2;
  var o = function(px, py, pr){ return {bubbles:true, cancelable:true, pointerId:1,
           pointerType:'touch', isPrimary:true, clientX:px, clientY:py, pressure:pr}; };
  el.dispatchEvent(new PointerEvent('pointerdown', o(x, y, 1)));
  el.dispatchEvent(new PointerEvent('pointermove', o(x+dx*0.5, y, 1)));
  el.dispatchEvent(new PointerEvent('pointermove', o(x+dx, y, 1)));
  el.dispatchEvent(new PointerEvent('pointerup', o(x+dx, y, 0)));
};
```

**滚动某屏（BetterScroll）**：`bsMap.get('screen-home').scrollTo(0, bsMap.get('screen-home').maxScrollY, 400)`

### 合成事件的三个伪影（别误判成 bug）
1. **合成 TouchEvent 不产生原生 click**：BetterScroll `click:true` 只对"被 preventDefault 的 target"（span 等）合成 click；纯文本按钮（target=BUTTON）走原生 click，合成测试验不到 → 用 `.click()` 直调或真机验证。
2. `adb input swipe` 注入的事件保真度差（被手势识别器消费），**验证手势一律用上面的合成事件**，别用 adb input。
3. 弹层/遮罩内的元素 `elementFromPoint` 会返回遮罩层子元素，取 target 前确认弹层状态。

## 6. 已踩坑清单（模拟器专属）

| 坑 | 现象 | 解法 |
|---|---|---|
| 网络栈假死 | 主机直连云函数通、WebView 全 `Failed to fetch` | 重启模拟器；先主机侧 python 直连区分网络/代码问题 |
| 时区 UTC | 模拟器"今天"比真机晚 8 小时（凌晨段差一天） | 日期逻辑已用 `localIso()` 本地组件切片，测试时注意两边日期可能不同 |
| adb 沙箱拒绝 | 个别终端 `拒绝访问` | 换新 Bash 会话 |
| arm64 APK | `INSTALL_FAILED_NO_MATCHING_ABIS` | 只装 universal/x86_64 包 |
| WebView 缓存旧前端 | 改了 css/js 不生效 | AssetServer 已加 `Cache-Control: no-store` + loadUrl 带 `?v=时间戳`；仍异常就 force-stop 重启 |
| 白屏（历史） | Google Fonts CDN 渲染阻塞 | 已移除 CDN，字体走系统回退 |
| 截图全黑/桌面 | App 没在前台 | 先 `am start` 再截 |
| **`adb kill-server` 是雷** | 执行后 MCP 与 Bash 同时 `no devices`，随后模拟器进程也退出（netstat 查 5554/5555 无监听可确认） | **永远不要 kill-server**；设备丢失时先换新 Bash 会话重试，仍不行就用 MCP `android_start_emulator(avd=medium_phone)` 重启（冷启动约 30 秒，磁盘数据/登录态不丢） |
